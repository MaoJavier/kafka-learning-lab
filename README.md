Kafka Learning Lab



Laboratorio práctico de Apache Kafka para aprender y experimentar con sistemas distribuidos y arquitecturas orientadas a eventos.



Objetivo



Construir un laboratorio progresivo que permita comprender Apache Kafka desde sus fundamentos conceptuales hasta su aplicación práctica con Java y Spring Boot.



Enfoque



Comprender los conceptos y mecanismos de Apache Kafka.



Implementar experimentos reproducibles.



Analizar escenarios de funcionamiento y fallo.



Documentar decisiones técnicas, resultados y limitaciones.



Estado actual



Feature 00 — Apache Kafka: Guía de aprendizaje



Esta etapa establece las bases conceptuales del laboratorio. Las siguientes etapas se definirán progresivamente.
